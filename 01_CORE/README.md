**Unveränderlich, aber strahlend.** Dieser Kern liefert den Endosymbiotic Spark an alle
anderen Schichten. Die 17 Layer werden nicht manuell editiert, sondern nur durch die Engine
aktualisiert (Layer Boot-Sequence: `NSEPlatform.start()`).
