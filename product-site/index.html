Frequently Asked

The objections, answered.

Yes. The container runs as non-root on your silicon. The weights, the state, the keys — all stay in your state/ directory. Apache-2.0 means you can fork, modify, and redistribute. There's no phone-home, no telemetry, no vendor endpoint.

A model API is a black box: you send tokens, you get tokens, you trust the provider. NSE-v5 is a sovereign organism: it runs 17 layers including its own verification (L08), governance (L11/L14), and legal gating (L17). You can prove every action it takes.

Layer 6 uses RestrictedPython: no builtins, no open(), no os.system. Shell commands only execute inside a read-only, caps-dropped, ephemeral container. File operations are jailed to a temp dir. It's a proof, not a hope.

The DAO layer (L11) is chain-agnostic — it works with EVM, Solana, or purely off-chain token registries. The multisig quorum (L17) is enforced by the platform itself, not by a specific chain's smart contract.

Layer 8 emits machine-readable proof artifacts for every critical invariant. You can verify them with nse status (shows proof-sealed state) or pipe them to an external auditor. The proof is the output; the run is the input.

Python 3.10–3.12, any OS with Docker. The Dockerfile is multi-stage: builder compiles C extensions, runtime is non-root with only the needed site-packages. K8s manifests and Terraform for scaling. No cloud lock-in.
